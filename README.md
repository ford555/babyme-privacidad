# Política de privacidad de BabyMe

Esta carpeta publica una sola página: la política de privacidad de la app
BabyMe, que Google Play exige tener en una dirección pública.

Se sirve con GitHub Pages en <https://ford555.github.io/babyme-privacidad/>.

El original vive en el repositorio de la app, en `docs/privacidad.html`.
Si cambia, se copia aquí como `index.html` y se hace commit y push; la
página se actualiza sola en un par de minutos.
